# 3D 모델 넣는 곳

여기에 `.glb` / `.gltf` 파일을 넣고, **`js/data.models.js` 의 `url` 한 줄만** 채우면 됩니다.
엔진 코드는 건드릴 필요가 없습니다.

```js
// js/data.models.js
champ: {
  jinx: { url: 'jinx.glb', scale: 1.0, yaw: 0, y: 0, fallback: 'humanoid' },
  //      ^^^^^^^^^^^^^^^ 이 줄만 추가
}
```

**파일이 없어도 게임은 정상으로 돌아갑니다.** `url` 이 `null` 이거나 로드에 실패하면
`fallback` 에 적힌 기본 도형으로 대체하고 콘솔에 한 줄 남깁니다.
그래서 에셋을 하나씩 구해 올 때마다 점진적으로 교체할 수 있습니다.

## 규약

| 항목 | 값 |
|---|---|
| 포맷 | **glTF 2.0** (`.glb` 권장 — 텍스처까지 한 파일) |
| 크기 기준 | 씬 1.0 = 리그 오브 레전드 **100 단위**. 챔피언은 높이 **약 1.1** 이 적당합니다 |
| 원점 | **발바닥**이 원점(0,0,0)에 오게. 아니면 `y` 로 올려 주세요 |
| 정면 | **+Z 방향**을 보게. 아니면 `yaw` 로 돌려 주세요 (뒤를 보면 `Math.PI`) |
| 업 축 | **+Y** (Blender 에서 내보낼 때 기본값) |

`scale` · `yaw` · `y` 는 모델을 다시 만들지 않고 맞추라고 있는 값입니다.
불러온 뒤 어긋나 보이면 이 셋만 조정하세요.

## 재질은 자동으로 카툰이 됩니다

불러온 GLTF 는 `applyToonMaterial()` 이 내부 Mesh 를 순회하며 **`MeshToonMaterial` 로 자동 변환**합니다.
`map`(색 텍스처) · `color` · `emissive` · `normalMap` · 투명도는 그대로 옮겨 담으므로,
**PBR 로 만든 모델을 그대로 넣어도** 리그 오브 레전드 특유의 핸드페인팅 느낌이 납니다.
같이 `castShadow` · `receiveShadow` 도 켜집니다.

이미 툰 텍스처가 구워진 모델이라면 그대로 두면 되고, 명암 단계를 바꾸고 싶으면
`render3d.js` 의 `LOOK.toonSteps` 를 만지세요 (콘솔에서 `Render3D.applyLook()` 로 즉시 반영).

## 어떤 것이 인스턴싱되나

| 대상 | 방식 | 제약 |
|---|---|---|
| 챔피언 (`champ`) | 개별 `Object3D` | 스킨 애니메이션 가능. 첫 클립을 자동 재생합니다 |
| 최종 보스 (`boss`) | 개별 `Object3D` | 스킨 애니메이션 가능 |
| 잡몹·정예 (`mob`) | **InstancedMesh** | 수백 마리가 한 번에 그려져야 해서 **스킨 없는 단일 메시**여야 합니다 |
| 지형지물 (`prop`) | **InstancedMesh** | 위와 같음 |

`mob`/`prop` 키는 **`ENEMY_TYPES` 의 `shape` 값**입니다. 같은 `shape` 를 쓰는 적끼리
하나의 `InstancedMesh` 를 공유하므로, 적이 400마리여도 드로우 콜은 늘지 않습니다.

## 어디서 구하나

**라이엇의 실제 챔피언 모델은 여기 들어 있지 않고, 제가 대신 구해 드리지도 않습니다.**
게임 클라이언트에서 추출된 파일이 여기저기 떠돌지만, 출처가 불분명한 바이너리를
받아서 프로젝트에 넣는 일은 하지 않습니다. 직접 구해 오시는 건 본인 판단입니다.

안전하게 쓸 수 있는 곳:

| 출처 | 라이선스 | 비고 |
|---|---|---|
| [Quaternius](https://quaternius.com) | CC0 | 저폴리 캐릭터·몬스터 팩이 많아 이 게임과 잘 맞습니다 |
| [Kenney](https://kenney.nl) | CC0 | 지형지물·소품이 특히 풍부합니다 |
| [Poly Pizza](https://poly.pizza) | CC0 / CC-BY | 검색이 편합니다 |
| Sketchfab | 필터에서 **Downloadable + CC0/CC-BY** 로 걸러서 | 라이선스 확인 필수 |
| Mixamo | 무료 | **애니메이션**을 붙일 때. 캐릭터에 리깅까지 해 줍니다 |

FBX만 있다면 Blender로 열어 glTF 2.0(.glb)으로 내보내면 그대로 쓸 수 있습니다.
애니메이션이 없는 모델은 Mixamo에 올려 리깅 + Idle/Run 클립을 받아 오면
`AnimationController` 가 바로 인식합니다(클립 이름을 매니페스트에 적어 주세요).

## 모델이 없을 때는

챔피언은 `render3d.js` 의 `CHAMP_BUILD` 가 **몸통 + 머리 + 손에 든 것**으로
9인을 서로 다르게 그립니다(레오나는 두껍고 방패, 징크스는 마르고 총 …).
`.glb` 를 넣으면 그 챔피언만 진짜 모델로 바뀌고 나머지는 그대로 실루엣을 씁니다.
