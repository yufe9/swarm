# 원작 집중포화(Swarm) 자료

출처: 나무위키 '집중포화' (2026-07-16 기준). 원작 재현의 **근거 자료**입니다.
`CLAUDE.md` 의 "내용물은 실제 리그 오브 레전드에서 가져옵니다" 규칙을 지킬 때 이 문서를 먼저 보세요.
수치는 **스킬 가속 0 · 난이도 보정 없음** 기준입니다.

---

## 1. 조작과 기본 구조

- `WASD` 이동, `E` 스킬, `R` 궁극기, **`C` 오토 타겟 온/오프**.
- 기본 공격(전용 무기)도 **무기로 판정** → 쿨다운이 있고 **스킬 가속이 곧 공격 속도**.
- 한 판 **15분**, 15분에 최종 보스전 시작.
- 레벨업 시 **무기 카드 + 기본 지속 효과 카드 3장 중 1택**.
- **무기 5칸 / 기본 지속 효과 6칸.** 각 5단계.
- **진화**: 무기 5단계 + 진화 조건 지속 효과 보유 + **접근 카드** 획득 → 프리즘 테두리 카드 등장 → 선택 시 진화.
  - 접근 카드는 **정예병 · 미니 보스 처치** 또는 **벨베스의 시험 클리어** 시 확정 드랍.
  - 카드는 바로 안 먹고 **모아둘 수 있음** (증강 '카드 수집가'가 이걸 노림).
- `Tab` 을 누르면 좌측에 어떤 지속 효과가 어떤 무기의 진화 조건인지 전부 표시.

> **우리 게임과의 차이**: 현재 구현은 보조 무기 4칸 / 아이템 4칸 · 4레벨이고, 진화는 '아이템 4레벨' 자체가
> 열쇠입니다. 원작은 **접근 카드라는 별도 드랍물**이 열쇠이고 지속 효과는 1레벨만 있어도 조건을 만족합니다.

## 2. 챔피언 9인

기본 체력은 대부분 **1,000**. 예외: 일라오이 1,500 / 브라이어 1,200.
기본 방어력: 레오나 **25**(최고) → 리븐 **20** → 야스오 **10** → 원거리 챔피언 **0**.
